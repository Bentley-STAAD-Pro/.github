## What Bentley STAAD.Pro Is

Bentley STAAD.Pro is a structural analysis and design workspace where steel and concrete members share one analytical model. Bentley STAAD.Pro member design reads the load combination results and checks sections against the code rules you select. Bentley STAAD.Pro steel and concrete checks stay beside the same geometry, so a review can see the frame, the governing combination, and the member result together. Load combinations are built from the primary cases before design runs.

Structural offices open Bentley STAAD.Pro when a frame mixes steel beams and concrete columns and both need code checks from one analysis. The analytical model holds joints, members, supports, and combinations together. Bentley STAAD.Pro keeps member design next to the geometry the team is reviewing.
